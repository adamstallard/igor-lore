# igor-lore

Lessons about working on [Igor](https://github.com/adamstallard/igor), and the configuration
for the Igor that works it.

Public because Igor is public: a lesson about a public codebase has nothing to hide, and
lore that cannot be read cannot be corrected.

Entries here were earned rather than invented — each cites the commit where the mistake was
made or the finding was recorded. An entry only fires once it is `active`, which happens by
review, not by being written.
